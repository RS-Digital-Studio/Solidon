# Updates bis zum 1. November

## Rhythmus

- **Einmal pro Woche, fest am Mittwoch**, dazu ein Update, wenn etwas
  passiert (Etappe erreicht, Version erschienen, Windows signiert). GoFundMe:
  „Successful GoFundMes typically post an update (or more) a week“
  ([How to post an update](https://support.gofundme.com/hc/en-us/articles/12553895153563-How-to-post-a-GoFundMe-update)).
- **Höchstens zwei pro Woche.** Jedes Update geht per E-Mail an alle
  Unterstützer; mehr wird zur Last.
- **Jedes Update hat:** ein Bild, eine Neuigkeit, einen Dank, eine Bitte ums
  Teilen. So empfiehlt es GoFundMe, und so bleibt jedes Update auch für Leute
  lesbar, die nur dieses eine sehen.
- **Nach jedem Update** über die drei Punkte daneben auf Facebook und WhatsApp
  teilen und im YouTube-Community-Tab kurz darauf hinweisen.
- **Nur Belegtes.** Keine Termine für Versionen, die nicht fertig sind. Zahlen
  aus dem Code, dem Changelog oder dem GoFundMe-Dashboard, nie geschätzt.
- Englisch jeweils als Block unter dem deutschen Text (siehe
  `kampagne-en.md`, Abschnitt 1).

Was in eckigen Klammern steht, setzt Robert am Tag des Updates ein.

### B: Windows signiert

**Änderungsvorschlag für die Veröffentlichung 0.5.0:** Erst einsetzen, wenn die Signaturen am endgültigen Windows-Installer und an der enthaltenen Anwendung geprüft sind und genau dieses Paket öffentlich verfügbar ist. Noch nicht auf GoFundMe veröffentlicht.

**Die Windows-Version ist jetzt signiert**

Ab Version 0.5.0 sind die Windows-Anwendung und die Setup-Datei von Solidon3D digital signiert. Die Signatur weist mich als Herausgeber aus und macht nachträgliche Änderungen erkennbar. Bei neuen Dateien kann Windows trotzdem einen SmartScreen-Hinweis anzeigen.

Das Zertifikat habe ich selbst bezahlt. Zusammen mit der Notarisierung bei Apple, die seit 0.4.1 steht, sind damit Windows und Mac beide signiert.

Danke fürs Mitlesen, und wenn du die Seite teilst, freue ich mich.
Robert
